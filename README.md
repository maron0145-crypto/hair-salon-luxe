# hair salon luxe

架空の美容室「Luxe（ラックス）」の公式Webサイトです。

## 概要

完全個室のプライベート美容室をコンセプトにした、静的Webサイトです。練習用プロジェクトとして制作しました。

## 技術スタック

- HTML
- CSS
- JavaScript

フレームワーク・ライブラリは使用していません。

## ページ構成

| セクション | 内容 |
|---|---|
| Hero | キャッチコピーと予約ボタン |
| Concept | サロンの3つのこだわり |
| Menu & Price | カット・カラー・パーマ等の料金表 |
| Stylist | スタイリスト紹介 |
| Reservation | お問い合わせフォーム |
| Footer | 店舗情報・Googleマップ |

## 主な機能

- レスポンシブデザイン（モバイル対応）
- ハンバーガーメニュー（スマートフォン向け）
- お問い合わせフォームのバリデーション
- スクロール時のヘッダー表示切替

## デプロイ

[Vercel](https://vercel.com/) でホスティングしています。
