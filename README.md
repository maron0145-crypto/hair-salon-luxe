# hair salon luxe

架空の美容室「Luxe（ラックス）」の公式Webサイトです。

## 概要

完全個室のプライベート美容室をコンセプトにした、静的Webサイトです。練習用プロジェクトとして制作しました。

## 技術スタック

- HTML
- CSS
- JavaScript

フレームワーク・ライブラリは使用していません。

## ページ構成

| セクション | 内容 |
|---|---|
| Hero | キャッチコピーと予約ボタン |
| Concept | サロンの3つのこだわり |
| Menu & Price | カット・カラー・パーマ等の料金表 |
| Stylist | スタイリスト紹介 |
| Reservation | お問い合わせフォーム |
| Footer | 店舗情報・Googleマップ |

## 主な機能

- レスポンシブデザイン（モバイル対応）
- ハンバーガーメニュー（スマートフォン向け）
- お問い合わせフォームのバリデーション
- スクロール時のヘッダー表示切替

## ターゲット層と設計思想

### ターゲット層

都心で働く30〜40代のビジネスパーソンを主なターゲットとする。  
具体的には次の3つの特性を持つ層に絞る。

- **SNS疲れ・人疲れ**を感じており、他者の視線から解放されたい
- 美容室での「他客との共有空間」に居心地の悪さを感じている
- 高単価でも「空間体験」に価値を見出す

### デザイン戦略の論理

#### 完全個室 × 都心 = 社会との隔離空間

競合8社を調査したところ、**6社がスタッフ顔写真を前面に出す**設計を採っている（Difino / Locaop / Reon / Beaurex / TENELE / PINCH）。  
この手法が解消しようとしている不安は「**誰が切るかわからない**」という技術への不信感だ。

Luxeが向き合うターゲットの不安は別にある。「**他の客に見られたくない**」「**社会から切り離されたい**」という、都市生活者特有の消耗感だ。  
完全個室はこの不安に直接応える。都心という立地（アクセスの良さ）と個室（社会との遮断）を掛け合わせることで、「日常から切り離された非日常体験」を現実の動線の中に組み込む。

#### 植物 = 都市と自然の対比による癒し

競合の中でPINCH Tokyoのみが植物をヒービジュアルに使っている。  
しかしPINCHはメディア露出を信頼の主軸に置いており、植物はあくまで内装の個性付けにとどまる。

Luxeはヒーローセクションとサロン空間の両方に植物を配置し、コンセプトの核に据える。  
都市の喧噪（コンクリート・人混み・情報過多）と自然（緑・静けさ・有機的な形）の対比を視覚的に演出することで、「ここに来ると息ができる」という感覚的な価値を訴求する。

### 競合との差別化まとめ

| 訴求軸 | 競合（多数派） | Luxe |
|---|---|---|
| 安心感の源泉 | スタッフの顔と名前 | 完全個室という空間保証 |
| 癒しの演出 | 暖色・ベージュ系の色使い | 植物による自然素材の導入 |
| ターゲットの不安 | 技術への不信 | 他者視線・社会的疲労 |
| 差別化の軸 | 「人（スタッフ）」 | 「空間（個室＋自然）」 |

競合がスタッフを前面に出すほど、「空間で差別化する」Luxeのポジションは明確になる。
